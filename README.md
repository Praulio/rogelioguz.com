# Rogelio Guzman Landing

Landing estatica para `rogelioguz.com`.

## Archivos

- `index.html` - pagina completa.
- `assets/operating-room.svg` - visual editorial de operacion a workflow.

## Deploy sugerido

Publicar solo esta carpeta en un repo publico separado, no el vault completo.

Para GitHub Pages:

1. Crear repo publico.
2. Subir `index.html`, `assets/` y, si se confirma dominio, `CNAME`.
3. Activar Pages desde `main` / root.
4. Configurar DNS de `rogelioguz.com` en Namecheap hacia GitHub Pages.
